## Tecnologías principales

- **Backend:** Node.js + Express (microservicios)
- **Bases de datos:** PostgreSQL (auth), MongoDB Atlas (historias), SQLite (offline móvil)
- **Caché:** Redis
- **Gateway:** Nginx
- **Orquestación:** Docker Compose
- **App móvil:** React Native + Expo

---

## Requisitos previos

- Node.js v20 LTS
- Docker Desktop
- Git
- Expo Go

---
